## 목차

### Git
- [git](Git/git.md): Git 기본 명령어 정리
  - `init`, `status`: 저장소 만들기, 현재 상태 확인
  - `add`, `commit`, `log`: 변경 내용 저장하고 기록 보기
  - `remote add`, `push`: GitHub 같은 원격 저장소에 올리기
  - `restore`, `rm --cached`: 변경 되돌리기, 추적 해제
  - `reset`, `stash`: 커밋 취소, 작업 잠시 치워두기
